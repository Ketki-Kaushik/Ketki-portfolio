# Rapido

## Workforce Management System

A project management capstone focused on designing a workforce management system for onboarding and managing Auto and E-Rickshaw drivers across cities.

The project explored workforce planning, field executive management, vendor coordination, HRMS, GPS-based attendance, centralized payments, project scheduling and risk management.

### Project Focus

- Workforce Management
- Driver Onboarding
- Vendor Management
- HRMS
- GPS Attendance
- Project Management
- Gantt Chart
- Network Diagram
- RACI Matrix
- Risk Management

### Key Learning

I learned how project management tools and structured workforce processes can be used to manage large-scale field operations efficiently.
